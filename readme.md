# Easy Update URLs

Easy Search and Replace in WP database. Expertly designed to find and replace any text, from URLs to branding.

## Description

Welcome! While its name highlights URL updates, this plugin is a comprehensive Search and Replace tool for your entire WordPress/ClassicPress database. 

It is expertly designed to find and replace any text, from URLs and image paths to recurring phrases or old branding, making it indispensable for site migrations, content overhauls, and routine maintenance.

**Key Features:**
* **Comprehensive Search & Replace:** Find and replace any text string across all database tables.
* **Effortless Site Migration:** Seamlessly update URLs and file paths when moving to a new domain.
* **Bulk Content Management:** Quickly update outdated information or fix broken links.

## Installation

1. Upload the `easy-update-urls` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in ClassicPress.
3. Navigate to 'Tools' -> 'Easy Search Replace' to begin.
